# ODYSSEY · THE HOMECOMING

改编自荷马史诗《奥德赛》的俯视角动作地牢 Demo。

原生 HTML5 Canvas 2D，**零依赖、零构建**：clone 下来双击 `index.html` 就能跑，不需要 `npm install`，也不需要打包。

## 怎么跑

```
双击 index.html
```

如果想用本地服务器（改代码后免手动刷新）：

```
npx serve .
# 或任意静态服务器指向仓库根目录
```

## 代码地图

| 文件 | 职责 | 改这个文件的场景 |
| --- | --- | --- |
| `index.html` | 整个游戏本体，单文件，按注释里的编号章节组织（画布工具 → 调色板 → 存档 → 音效 → BGM → 玩家 → 输入 → 关卡流程 → 碰撞 → 粒子 → 更新 → 场景绘制 → 角色绘制 → HUD → 渲染 → 主循环） | 改玩法、战斗、绘制、UI |
| `data.js` | 关卡与数值配置：三幕 12 间房、敌人属性、道具定义 | 调房间顺序、敌人血量、道具数值，**不需要动逻辑** |
| `lang.js` | 中 / 英 / 日三语词条，以英文原文为键 | 加任何界面文案 |
| `DESIGN.md` | 设计文档 v0.5，系统与关卡设定的**唯一来源** | 改设定、加机制前先改这里 |
| `ITEMS.md` | 24 件道具的逐件图鉴 + 套装共鸣 | 查道具设计意图 |
| `prototypes/` | 画风原型，不属于游戏本体 | 探索新画风时用 |

几个容易踩的点：

- 逻辑分辨率 **480×270**，物理画布 **960×540**（`RS = 2` 双倍渲染）。绘制按逻辑坐标写，`ctx.setTransform` 之后不要手动乘 2。
- 文字走物理像素绘制，所以中日文是清晰的系统字体，不是像素字。
- 房间边界、刷怪点、石柱位置都在 `data.js` 的 `room` 字段里，不在代码里硬编码。

## 画风路线

第一、二幕保持像素风，第三幕整体切换成手绘风（粗黑描边、扁平色块、手绘抖动线条）。这是刻意做成"一次性风格突变"，接进游戏时会配一段约 3 秒的画面转场。设计理由见 `DESIGN.md`。

`prototypes/proto-vase.html` 是另一条被否掉的路线（古希腊黑绘陶瓶），留作记录。
